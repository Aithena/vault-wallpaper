# 管理后台 P0 列表字段验收表

> 配合 [`admin-ia.md`](./admin-ia.md) 使用。仅覆盖 **P0** 必做页；P1/P2 字段不在此表强验收。  
> 发版前关键冒烟见 [`admin-smoke-checklist.md`](./admin-smoke-checklist.md)。
>
> 最后更新：2026-08-07

## P0 范围回顾

| 必做 | 说明 |
|------|------|
| 布局壳 A–F | 见 [`admin-ia.md`](./admin-ia.md) §2：顶栏 A、一级 C、二级 E、内容 F；整页左上→右下渐变 |
| 管理员登录 | 白名单 / 后台账号登录（实现时二选一或组合，需能进后台） |
| 3.1 壁纸列表 | 审核流 + 单张上传（批量上传可 P1 再打磨） |
| 3.2 / 3.3 | 分类、标签 CRUD |
| catalog | 替代 `SEED_WALLPAPERS`，C 端读持久化目录 |
| 2.1 用户列表 | 基础信息 + 禁用/解封（手动续费出单属 P1） |
| 4.1 全部订单 | **只读**列表，含 0 元单 |
| 6.5 操作日志 | 关键写操作打点，列表可简 |

占位页（1.1、4.2、6.1–6.3、6.6 等）P0 只需侧栏可进空页即可，无字段验收。

## 2.1 用户列表

### 筛选

| 筛选项 | P0 | 备注 |
|--------|----|------|
| 付费会员 / 免费用户 | ✅ | 付费 = 当前有效会员且档位非 free（或 `memberStatus=active` 且未过期） |
| 注册时间 | ✅ | 起止日期 |
| 是否拉黑 | ⬜ P1 | 黑名单模块 P1；P0 可不展示该筛 |

### 列表列

| 列 | 必显 | 示例 / 说明 |
|----|------|-------------|
| 邮箱 | ✅ | |
| 会员档位 | ✅ | free / basic / pro / max / 无 |
| 会员状态 | ✅ | active / 已过期 / 未开通 |
| 到期时间 | ✅ | `memberExpiresAt`，无则 — |
| 注册时间 | ✅ | `createdAt` |
| 账号状态 | ✅ | 正常 / 已禁用 |

### 行内操作

| 操作 | P0 | 备注 |
|------|----|------|
| 查看 / 编辑资料 | ✅ | P0 可先只读详情 + 禁用；编辑邮箱等谨慎开放 |
| 禁用 / 解封 | ✅ | 打用户日志 + 全局操作日志 |
| 操作日志 | ✅ | 该用户维度；P0 可弹层/子页，条目可少 |
| 手动续费 / 开通 | ⬜ P1 | 须出 `admin_grant` 订单 |

### 验收要点

- [ ] 禁用后该用户无法再带旧 token 下载（session 失效或鉴权拒绝）
- [x] 列表分页或「加载更多」在数据量小时可先 limit + 简单翻页（已接 `page`/`pageSize`）

## 3.1 壁纸列表

### 筛选 / 顶栏

| 项 | P0 |
|----|----|
| 按状态：待审核 / 已驳回 / 已上架 / 已下架 | ✅ |
| 按分类 | ✅ |
| 关键词（标题） | ✅ 建议有 |
| 单张上传入口 | ✅ |
| 批量上传 | ⬜ 可延后，有入口占位亦可 |

### 列表列

| 列 | 必显 | 说明 |
|----|------|------|
| 预览缩略图 | ✅ | `previewUrl` |
| 标题 | ✅ | |
| ID | ✅ | 与 R2 `originals/{id}.jpg` 对应 |
| 状态 | ✅ | 待审核 / 已驳回 / 已上架 / 已下架 |
| 所需档位 | ✅ | `tierRequired` |
| 分类 | ✅ | |
| 标签 | ✅ | 可逗号摘要 |
| 尺寸 | ✅ | width × height |
| 原图 | ✅ | 已传 / 缺失 |
| 更新时间 | ✅ | |

### 行内操作

| 操作 | P0 | 条件 |
|------|----|------|
| 审核通过 | ✅ | 仅待审核；**原图必须已传** |
| 驳回 | ✅ | 仅待审核；**必填理由** |
| 下架 | ✅ | 仅已上架 |
| 编辑 | ✅ | 元数据；改完若已上架是否回待审：P0 建议「已上架编辑后仍保持上架」，重大字段变更可后续再收紧 |
| 删除 | ✅ | 软删 |
| 补传原图 | ✅ | 原图缺失时 |

### 批量操作（P0 最低集）

| 操作 | P0 |
|------|----|
| 批量审核通过 | ✅ |
| 批量下架 | ✅ |
| 批量删除 | ✅ |
| 批量改分类 | ⬜ P1 可打磨 |

### 上传表单字段（单张）

| 字段 | 必填 | 说明 |
|------|------|------|
| 标题 | ✅ | |
| 所需档位 | ✅ | |
| 分类 | ✅ | 至少一个或允许「未分类」需产品定；建议 P0 必选分类 |
| 标签 | 可选 | 多选 |
| 宽度 / 高度 | ✅ | 可手填；有原图后可后续自动读 |
| 预览图 | ✅ | URL 或上传到 R2 previews |
| 原图文件 | ✅ 上架前 | 可先存元数据再补传，但通过审核前必须有 |

### 验收要点

- [ ] C 端 `GET /api/wallpapers` 只返回 **已上架** 且未软删
- [ ] 下载接口对未上架 / 无原图返回明确错误
- [ ] 驳回后状态为「已驳回」，列表可筛出
- [ ] 已下架再上架 → 回到「待审核」

## 6.5 全局操作日志

### 列表列

| 列 | 必显 |
|----|------|
| 时间 | ✅ |
| 管理员 | ✅ |
| 动作 | ✅ | 如 `wallpaper.approve`、`user.disable` |
| 对象 | ✅ | 类型 + id / 摘要 |
| IP 或 User-Agent | 可选 |

### P0 必须打点的动作

- [ ] 壁纸：通过 / 驳回 / 下架 / 删除 / 创建（上传）
- [ ] 分类 / 标签：增删改
- [ ] 用户：禁用 / 解封
- [ ] 管理员登录成功（建议）

### 验收要点

- [ ] 上述写操作后列表能查到对应条目
- [ ] 普通 C 端用户行为不进本列表

## 管理员登录（P0 门槛）

| 项 | 验收 |
|----|------|

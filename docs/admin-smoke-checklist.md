# 管理后台冒烟与上线检查

> 配合 [`admin-p0-acceptance.md`](./admin-p0-acceptance.md)、[`admin-ia.md`](./admin-ia.md)。  
> 用于发版前人工过一遍关键路径；不替代自动化测试。  
> 最后更新：2026-08-07

## 环境准备

| 项 | 检查 |
|----|------|
| Admin / API / Web 本地或预发可访问 | ☐ |
| 种子超管可登录（如 `admin` / `admin123`） | ☐ |
| 至少 1 个 `dataScope=self` 的运营账号（用于权限对照） | ☐ |
| R2 / 支付 / 邮件按环境配置（预发可 mock） | ☐ |

---

## A. 禁用 / 拉黑

| # | 步骤 | 期望 | ☐ |
|---|------|------|---|
| A1 | 用户列表禁用某邮箱 | 账号状态「已禁用」；全局审计有 `users` 禁用记录；用户日志有条目 | ☐ |
| A2 | 该用户带旧 session 访问需登录接口 / 下载 | 拒绝（401/403 或明确禁用错误） | ☐ |
| A3 | 解封同一用户 | 可重新登录并正常浏览 | ☐ |
| A4 | 拉黑用户（填原因） | 列表「拉黑=是」；**仍可登录** | ☐ |
| A5 | 拉黑用户下单 / 下载 | **不可购买、不可下载**；错误明确 | ☐ |
| A6 | 解除拉黑 | 可再次购买与下载 | ☐ |

---

## B. 壁纸审核 / 上下架

| # | 步骤 | 期望 | ☐ |
|---|------|------|---|
| B1 | 单张上传元数据（无原图） | 状态待审核；列表可见；原图「缺失」 | ☐ |
| B2 | 对待审且无原图点「通过」 | 失败 / 禁用，提示需原图 | ☐ |
| B3 | 补传原图后再通过 | 状态已上架；C 端列表可见 | ☐ |
| B4 | 驳回（必填理由） | 状态已驳回；可筛出 | ☐ |
| B5 | 已上架 → 下架 | C 端不可见 / 不可下 | ☐ |
| B6 | 已下架 / 已驳回 → 再提审 | 回到待审核，不可直接上架 | ☐ |
| B7 | 批量通过 / 下架 / 删除 / 改分类 | 成功/失败计数正确；审计有 batch 记录 | ☐ |
| B8 | 批量上传（开同步预览）后列表 AI 列 | 出现「识别中」或「已就绪」；编辑页可见描述与建议分类标签 | ☐ |
| B9 | 审核确认页「采用 AI 建议」并保存后通过 | 正式分类/标签/描述已写入；C 端可见上架图 | ☐ |

---

## C. 下载

| # | 步骤 | 期望 | ☐ |
|---|------|------|---|
| C1 | 有效会员下载已上架有原图壁纸 | 成功；后台「下载记录」有成功行 | ☐ |
| C2 | 档位不足 / 未登录 / 未上架 | 失败；下载记录有失败原因（若已打点） | ☐ |
| C3 | 下载列表分页与筛选 | 翻页、按成功/失败/关键词可用 | ☐ |

---

## D. 改价 / 站点

| # | 步骤 | 期望 | ☐ |
|---|------|------|---|
| D1 | 档位管理修改某档 `price` 并保存 | 审计有 `settings.tiers.save` | ☐ |
| D2 | C 端 `GET /api/site/tiers` 或会员页 | 展示新价 | ☐ |
| D3 | 关闭 `purchaseEnabled` | C 端无法创建付费单 | ☐ |
| D4 | 档位 `onSale=false` | 该档不可购 | ☐ |
| D5 | 恢复购买开关与上架态 | 可正常下单（或 mock 支付） | ☐ |

---

## E. 数据权限 `self`

| # | 步骤 | 期望 | ☐ |
|---|------|------|---|
| E1 | `self` 账号登录 | 壁纸/分类/标签/公告列表仅本人创建 | ☐ |
| E2 | 尝试改他人壁纸 ID（直调 API） | `403 forbidden_scope` | ☐ |
| E3 | 全局操作日志 | 仅本人操作（或与角色约定一致） | ☐ |
| E4 | 用户 / 订单 / 下载菜单若已授权 | 仍为全量（无归属过滤） | ☐ |

## G. 上线检查（运维）

| # | 项 | ☐ |
|---|----|---|
| G1 | 生产 KV / R2 / Secrets（JWT、支付、Resend 等）已配置且非开发 mock | ☐ |
| G2 | 超管密码已改；种子弱密码未暴露到公网 | ☐ |
| G3 | CORS / 域名与 C 端、Admin 一致 | ☐ |
| G4 | 关闭或保护调试路由（mock 支付等） | ☐ |
| G5 | 关键路径冒烟：登录 → 禁用/拉黑 → 审核 → 下载 → 改价各至少 1 次 | ☐ |
| G6 | 回滚预案：上一版 Worker / 静态资源可知 | ☐ |
